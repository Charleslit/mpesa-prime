# My oneAPP

M-PESA-style mobile web app built with TanStack Start, React, TypeScript, and Tailwind CSS. Includes Capacitor Android packaging.

## Development

```sh
npm i
npm run dev
```

## Scripts

- `npm run dev` — local development server
- `npm run build` — production web build
- `npm run build:mobile` — static Capacitor client build
- `npm run cap:sync` — build mobile assets and sync Android
- `npm run android:apk` — build a debug/release APK

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
- Capacitor
